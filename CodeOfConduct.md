# Code of Conduct 

## Purpose 

This code of conduct outlines the expectations for all members of group 7. 
It is intended to promote a respectful, collaborative, and productive working enviornment.

## Team Expectations

ALl team members agree to:

- Treat each other with respect and professionalism at all times.
- Communicate clearly and in a respectful manner.
- Contribute fairly to the project.
- Attend scheduled meetings/stand-ups or notify the team in advance if unable to attend.
- Complete assigned tasks by agreed deadlines, if an individual is struggling with a task, they can ask for help from the rest of the group.
- Use the tools for the project such as GitHub, responsibly.
- Raise concerns or issues with the rest of the group.

## Collaboration

Team Members should:

- Share progress regularly 
- Review or test their work before submitting changes.
- Avoid making changes that could negatively impact another members work without discussion.
- Keep documentation up to date.

## Unacceptable Behaviour

The following classes as unacceptable behaviour:

- Harassment, discrimination or personal attacks.
- Repeated failure to communicate with the team.
- Plagiarism or submitting someone else's work as your own.
- Disrupting the project or deleting team work without permission.

## Resolving Issues

If an argument occurs, team members should:

- Discuss the issue respectfully within the group
- Attempt to reach a mutually acceptable solution.
- Seek guidance from module tutor or lecturer if necessary.

## Agreement

By participating in this project, all team members agree to follow this code of conduct and contribute positively to the success of the group.
